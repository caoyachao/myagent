# MyAgent 2.0 架构设计

## 核心设计思想

MyAgent 2.0 是一个**多智能体记忆增强层**，在 1.0 的基础上增加了：
- 多智能体支持
- 智能体间记忆隔离
- 技能继承系统
- 智能体身份标识

## 数据存储结构

```
~/.local/share/myagent/
├── master/                          # 主智能体数据
│   ├── agent.json                   # 主智能体配置
│   ├── memories.db                  # 主智能体记忆
│   └── chroma/                      # 主智能体向量库
├── agents/                          # 其他智能体数据
│   └── agent-{uuid}/
│       ├── memories.db              # 私有记忆
│       └── chroma/                  # 私有向量库
└── current_agent.json               # 当前激活智能体状态

~/.config/myagent/
├── shared_skills/                   # 共享技能
│   ├── code_assistant/
│   └── personal_assistant/
├── agents/                          # 智能体私有配置
│   └── agent-{uuid}/
│       ├── agent.json               # 智能体配置
│       └── skills/                  # 私有技能
└── master/
    └── agent.json                   # 主智能体配置
```

## 核心模块

### 1. AgentManager
管理所有智能体的 CRUD 和切换：
- `create_agent()` - 创建新智能体
- `list_agents()` - 列出所有智能体
- `switch_agent()` - 切换当前智能体
- `delete_agent()` - 删除智能体
- `get_current_agent()` - 获取当前智能体

### 2. AgentAwareMemoryStore
智能体感知的记忆存储：
- 每个智能体有独立的 SQLite + ChromaDB
- 支持从主智能体继承记忆
- 自动在智能体间隔离数据

### 3. AgentAwareSkillRegistry
智能体感知的技能注册表：
- 组合共享技能和私有技能
- 私有技能优先于共享技能
- 根据继承设置动态加载

### 4. AgentAwareMCPServer
增强的 MCP 服务：
- 所有工具返回带智能体标识
- 动态根据当前智能体提供功能
- 系统提示词包含智能体身份

## 回复格式

所有回复都以【智能体名称】开头：

```
【编程助手】已找到相关代码片段...
【写作助手】这是根据你的要求写的文章...
【默认助手】有什么可以帮你的吗？
```

## 数据迁移

从 1.0 到 2.0 的自动迁移：
- `memories.db` → `master/memories.db`
- `chroma/` → `master/chroma/`
- `skills/` → `shared_skills/`

迁移时自动创建备份：`backup_v1.0_*`

## 删除清理

删除智能体时清理：
- SQLite 数据库文件
- Chroma 向量存储目录
- 私有技能目录
- 配置文件
- 缓存文件
- 空目录

## 安全考虑

1. 主智能体不可删除
2. 删除前需要确认
3. 自动创建备份
4. 支持回滚操作
